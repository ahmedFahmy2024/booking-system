# Review the booking workflow

1. Find one concrete point where work repeated, stalled, or needed avoidable user intervention. Use an observed detail from the task, such as the same failed command twice, a stale instruction, or a missing prerequisite discovered late. Stop if the task produced no evidence of friction.
2. Trace it to a cause. Choose one reusable improvement at the source, such as correcting a skill command, adding a prerequisite to the verification doctor, or clarifying how a checkpoint preserves evidence. For a one-off issue, handle it in the task and end the review.
3. Define a check for the improvement. For example, the doctor should identify a missing fixture before Playwright starts, or the next chat should find the pending check from the checkpoint. Apply a small project workflow fix when it fits the authorized scope. Otherwise, report it as a proposal with the check and the place to make the change.
4. Report the friction, evidence, improvement, and result of the check in the task handoff. If the check requires a later task, state what to observe next time.
